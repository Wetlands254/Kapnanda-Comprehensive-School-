# Deployment Checklist

1. Create a new GitHub repository for Kapnanda.
2. Upload `index.html`, `style.css`, `app.js`, `supabase-schema.sql`, `README.md`, `SECURITY.md`, and `SUPABASE-SETUP.md`.
3. In Supabase, create a new project or use a dedicated school project.
4. Run `supabase-schema.sql` in Supabase SQL Editor.
5. Open the deployed site.
6. Sign in using the local administrator account for initial setup, or configure Supabase Auth.
7. Go to Settings and set the school period, subjects and other configuration.
8. Add teachers.
9. Add learners by class/grade.
10. Add assessments and enter marks.
11. Test Reports by selecting a Grade/Class and confirming the complete learner list appears.
12. Generate, print and download a sample learner report.
13. Confirm Backup works before entering live data.
