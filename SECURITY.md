# Security

- Never put a Supabase service-role key in `index.html` or `app.js`.
- Use the Supabase publishable/anon key only in the browser.
- Configure Supabase Auth for real school users.
- Keep learner, marks, attendance and fee data protected by Row Level Security.
- Change the default local administrator password immediately.
- Do not publish real learner data in a public Git repository.
