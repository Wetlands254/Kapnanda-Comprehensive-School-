# Kapnanda School Management System — Print & PDF Standards

All printable academic documents follow these rules:

1. **A4 portrait** is the default for rankings, class lists, learner reports, attendance registers and academic summaries.
2. **A4 landscape** is reserved for timetables where the wider layout is necessary.
3. Print controls, navigation, search boxes and buttons are hidden automatically.
4. School colours, table headings, grade colours and banners are preserved with print-colour adjustment enabled.
5. Documents use consistent A4 margins and are centred on the page.
6. **Grade/Class Ranking** is designed as a single full-page A4 document and must not shrink into a small block at the top of the paper.
7. Ranking PDF export and browser printing use the same A4 layout.
8. Bulk learner reports use one learner report per A4 page.
9. PDF export stages are kept inside the printable document area rather than being positioned far off-screen, preventing blank/empty PDFs in browsers that cannot render off-screen content.
10. Where a document genuinely needs multiple pages, page breaks are controlled deliberately instead of allowing random splits.

For the cleanest colour output, enable **Background graphics / Background colours** in the browser's print dialog when that option is available.
